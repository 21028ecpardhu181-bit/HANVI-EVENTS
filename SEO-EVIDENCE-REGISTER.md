## 4. Engineering & Content Standards

1. **Search Intent over Word Counts**: Every page must comprehensively satisfy user intent with original, structured information. Never write fluff just to hit an arbitrary word count.
2. **Real Performance over Synthetic Badges**: Core Web Vitals (LCP, CLS, INP) must be kept optimal through clean Next.js server components, optimized assets, and zero layout shift.
3. **Server-Side Rendered Answers**: FAQs must be pre-rendered in semantic HTML `<details>` elements for instant crawler and LLM indexing without client JS execution.
4. **No Deprecated FAQ Schema**: Do not inject `FAQPage` JSON-LD schema on commercial service pages (restricted by Google since August 2023). Use valid `LocalBusiness`, `Service`, `Person`, and `BreadcrumbList` schemas.
